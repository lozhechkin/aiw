# Working in this workspace

1. Start by reading the selected project's PROJECT.md, TASKS.md and HANDOFF.md.
2. Find the desired outcome and what would prove it. Ask only when you need a decision or cannot proceed within the request.
3. Work within the project and the access the owner grants. Keep credentials and unrelated private material out of working documents. Get explicit permission before sharing, publishing, deleting, or expanding access.
4. Before reporting success, verify the result. Give the owner the file path, version, or check that supports it. Name any unverified part or blocker.
5. Update the task record and leave a handoff with the last verified result and the next step. A later chat should be able to continue using the project files.
