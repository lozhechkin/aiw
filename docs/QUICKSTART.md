# Your first task across two chats

1. Run the commands from the README in an extracted copy or clone of this repository. Use an empty workspace folder and leave the release files separate from your project data.
2. Open the `demo` directory under `10 Projects`. Give your first assistant the workspace `AGENTS.md` and its three project files. If the assistant only reads attachments, save its outputs yourself.
3. Ask it to draft a short invitation to a fictional 30-minute book discussion. Leave the tone undecided, save the draft as `RESULT.md`, and record the result and open decision in `HANDOFF.md`. No invitation should be sent.
4. Open a new chat. Give it the project files and `RESULT.md`. Ask it to identify the last result and suggest a neutral and a friendly opening. Have it save the options in `NEXT.md`.
5. Check the outcome. The second chat should find the draft and name the unresolved decision from the files, without a recap of the first chat.

If the new chat cannot see a file, attach it or grant scoped access to that project. Check the permissions before doing the same with personal or confidential material.
