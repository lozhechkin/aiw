# Changelog

## 0.2.0

- Added a read-only setup doctor for local Drive paths and Git availability.
- Added a repeatable setup command that preserves existing project files and refuses a conflicting repository link. It can also clone or verify a checkout in the same command.

## 0.1.0

- Initial English-language local starter.
- Added workspace initialization, project creation, and a read-only layout check.
- Included a two-chat exercise to demonstrate a verifiable handoff.
- Added a Google Drive desktop sync workflow and GitHub repository linking and cloning.
- Added an English walkthrough for a pull request handoff and a versioned roadmap.
- Added Google Docs plain-text read, revision-guarded append, and readback.
- Added a read-only GitHub PR head and CI report.
- Licensed the public starter under MIT.
